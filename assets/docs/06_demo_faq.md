# Demonstration FAQ

## Are the sample vehicle values real?

No. The profile and task schedule are synthetic and must not be used in production documents.

## Can the Agent answer an official eligibility question?

Only if an authorized, current source is available in the target knowledge base. This repository includes no official regulatory corpus. The model must not infer eligibility from the demo files.

## What should happen when values cannot be compared?

The parameter tool should mark the item for manual review when unit conversion requires missing context, such as voltage for converting mAh to kWh.

## Does a low-risk scan mean the submission is ready?

No. The scan evaluates only the task fields supplied by the user and does not validate technical evidence or official submission requirements.
